# WhatsApp Chat Analysis

This project analyzes **WhatsApp chat data** to extract insights about user activity, message patterns, emojis, and shared links.

## Features
- **Text Processing:** Cleans and structures WhatsApp chat data.
- **Emoji & URL Analysis:** Extracts and analyzes emojis and links in messages.
- **Message Frequency:** Identifies active users and message trends.
- **Data Visualization:** Uses multiple libraries for graphical representation.

## Technologies Used
- **pandas** (Data manipulation)
- **seaborn & matplotlib** (Data visualization)
- **re** (Text pattern matching)
- **emoji** (Extracts emojis from messages)
- **urlextract** (Finds URLs in chat data)

## Installation
Install the required dependencies:
```bash
pip install pandas matplotlib seaborn emoji urlextract
```

## Usage
1. Clone the repository:
```bash
git clone https://github.com/yourusername/Whatsapp_Chat_Analysis.git
cd Whatsapp_Chat_Analysis
```
2. Run the Jupyter Notebook:
```bash
jupyter notebook Whatsapp_Chat_Analysis.ipynb
```
3. Follow the notebook instructions to preprocess chat data and generate insights.
